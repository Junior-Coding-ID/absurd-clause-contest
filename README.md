Entry for [The Absurd Clause Contest](https://make.fun) on make.fun — one absurd clause hidden deep inside a terms-of-service agreement, in a single sentence of at most 200 characters.

## Run

```sh
node main.ts
```

`main.ts` writes the final clause to `entry.txt` (and to `/output/entry.txt` when available), then reads it back byte-per-byte and self-checks it: 156 characters, within the 1–200 character gate, exactly 1 sentence.

## Entry

> Notice of any fee increase shall be deemed received when the Company inserts it into the song stuck in your head; humming the chorus constitutes acceptance.
